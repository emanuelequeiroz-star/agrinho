# 🌱 Agro Forte - Futuro Sustentável

## 📖 Sobre o Projeto

O **Agro Forte** é um site informativo que apresenta a importância de um equilíbrio entre a **produção agrícola** e a **preservação ambiental**.  
O site mostra práticas sustentáveis e oferece um formulário de contato para interação com o público.

---

## 🎯 Objetivos

- Divulgar práticas agrícolas sustentáveis.
- Promover a conscientização ambiental.
- Criar um site simples, moderno e interativo usando HTML, CSS e JavaScript.
- Demonstrar técnicas de desenvolvimento web básicas.

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

---


## ✨ Funcionalidades

### Página Inicial
- Título e descrição do projeto.
- Botão "Saiba Mais" com **scroll suave** para a seção de sustentabilidade.

### Sustentabilidade
- Lista de práticas sustentáveis:
  - Uso racional de água
  - Redução de agrotóxicos
  - Recuperação de áreas degradadas
  - Energia renovável no campo

### Contato
- Formulário simples com campos obrigatórios: nome, email e mensagem.
- Mensagem de sucesso ao enviar ou aviso de preenchimento obrigatório.

---

## 🚀 Como Executar

1. Baixe os arquivos do projeto ou clone o repositório.
2. Certifique-se de que **index.html, style.css e script.js** estão na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador moderno.

---

## 🌎 Tema

**Agro Forte – Futuro Sustentável: equilíbrio entre produção agrícola e meio ambiente.**  
O site reforça que é possível produzir alimentos de qualidade sem prejudicar o meio ambiente.
